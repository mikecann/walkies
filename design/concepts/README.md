# Concept art

Made with Gemini 3 Pro Image through OpenRouter (19 October 2026), using screenshots of the app's Geographe map as layout references. The prompts are in `prompts/`.

- `1-satellite-clouds.jpg`: the round 1 pick. Real satellite map with game clouds over the unexplored parts. Chosen because Apple Maps satellite view makes it buildable.
- `1-civ-parchment.jpg`: round 1 runner-up. Unexplored hexes as an inked parchment map, explored hexes in colour. Liked for showing where the roads go before you've walked them.
- `2-honeycomb-clouds.jpg`: round 2. Continuous clouds whose edge steps along the hex grid.
- `2-dotted-roads.jpg`: **the direction we're building.** Clouds over unwalked tiles, with the streets underneath drawn across them as white dotted lines, so you can plan a route.
